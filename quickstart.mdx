## Prerequisites

- A Dirt IQ account ([sign up free](https://app.dirtiq.com/signup))
- An API key from your [dashboard](https://app.dirtiq.com/api-keys)
- A valid `event_id` for an upcoming or recent race event

---

## Step 1: Get your API key

Log in to the [Dirt IQ dashboard](https://app.dirtiq.com), navigate to **Settings → API Keys**, and create a new key. Copy it — you'll need it in the next step.

<Warning>
  Keep your API key secret. Never commit it to source control or expose it in client-side code.
</Warning>

---

## Step 2: Make your first prediction request

Send a `POST` request to `/predictions` with an event ID and division. Dirt IQ will return ranked win probabilities for every driver entered in that event.

<CodeGroup>

```bash cURL
curl -X POST https://api.dirtiq.com/v1/predictions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "event_id": "evt_2024_knoxville_nationals",
    "division": "sprint_wing"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.dirtiq.com/v1/predictions",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "event_id": "evt_2024_knoxville_nationals",
        "division": "sprint_wing"
    }
)

prediction = response.json()
print(prediction["drivers"][0])  # top-ranked driver
```

```javascript Node.js
const response = await fetch("https://api.dirtiq.com/v1/predictions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    event_id: "evt_2024_knoxville_nationals",
    division: "sprint_wing"
  })
});

const prediction = await response.json();
console.log(prediction.drivers[0]); // top-ranked driver
```

</CodeGroup>

## Step 3: Understand the response

A successful response returns a `Prediction` object with a ranked `drivers` array:

```json
{
  "id": "pred_01hx7k2m",
  "event_id": "evt_2024_knoxville_nationals",
  "track_id": "trk_knoxville",
  "division": "sprint_wing",
  "track_condition_score": 62.4,
  "confidence": 0.81,
  "created_at": "2024-08-10T18:30:00Z",
  "drivers": [
    {
      "driver_id": "drv_9",
      "name": "Donny Schatz",
      "car_number": "15",
      "win_probability": 0.19,
      "podium_probability": 0.48,
      "top5_probability": 0.67,
      "projected_finish": 2,
      "form_score": 88.3,
      "track_affinity": 94.1
    },
    {
      "driver_id": "drv_17",
      "name": "David Gravel",
      "car_number": "2",
      "win_probability": 0.16,
      "podium_probability": 0.43,
      "top5_probability": 0.61,
      "projected_finish": 3,
      "form_score": 91.2,
      "track_affinity": 78.5
    }
  ]
}
```

Key fields to know:

| Field | Description |
|---|---|
| `win_probability` | Probability (0–1) of winning the feature |
| `podium_probability` | Probability (0–1) of finishing top 3 |
| `track_condition_score` | Composite score 0 (slick) → 100 (heavy moisture) |
| `confidence` | Overall model confidence for this prediction |
| `form_score` | Rolling 30-day performance score (0–100) |
| `track_affinity` | Historical performance score at this track (0–100) |

## Step 4: Subscribe to live updates (optional)

Register a webhook endpoint to receive updated predictions as conditions change throughout the race night:

```bash
curl -X POST https://api.dirtiq.com/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourapp.com/webhooks/dirtiq",
    "events": ["prediction.updated", "track_conditions.changed"]
  }'
```

See the [Webhooks reference](/api-reference/endpoint/webhook) for the full payload schema and verification guide.
