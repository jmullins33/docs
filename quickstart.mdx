## Get started in three steps

Stand up the prediction database locally and load a season of Lucas Oil Late Model
Dirt Series results.

### Step 1: Set up the database

<AccordionGroup>
  <Accordion icon="database" title="Create the schema">
    Create a PostgreSQL database and apply the schema described in
    [Database schema](/data/schema). It defines the core tables: `drivers`,
    `tracks`, `races`, `entries`, `results`, and `qualifying`.
  </Accordion>
  <Accordion icon="download" title="Pull in results">
    Load historical race results from your chosen [data sources](/data/sources).
    Start with one full season so the prediction model has enough history to work
    with.

    <Tip>A single season is enough to test the pipeline, but 3+ seasons produce noticeably better win probabilities.</Tip>
  </Accordion>
</AccordionGroup>

### Step 2: Normalize the data

<AccordionGroup>
  <Accordion icon="user" title="Match drivers and tracks">
    Driver and track names vary between sources ("Jonathan Davenport" vs
    "J. Davenport"). Follow [Drivers & tracks](/data/drivers-tracks) to map every
    raw name to a single canonical ID before scoring.
  </Accordion>
  <Accordion icon="circle-check" title="Validate a season">
    Spot-check finishing order, lap counts, and feature winners against the
    official results so bad rows don't poison your predictions.
  </Accordion>
</AccordionGroup>

### Step 3: Make a prediction

<Accordion icon="trophy" title="Run the model">
  With clean data loaded, follow [Predicting winners](/predictions/winners) to
  generate win probabilities for an upcoming race, then [Predicting props](/predictions/props)
  for fast time, top fives, and hard charger.
</Accordion>
