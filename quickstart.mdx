## Prerequisites

- A Dirt IQ operator account and API key — contact [sales@dirtiq.com](mailto:sales@dirtiq.com)
- A licensed series in your contract (e.g., `lucas_oil_late_models`)
- An HTTPS endpoint on your side to receive webhook pushes (optional but recommended)

---

## Step 1: Retrieve the event list

Fetch upcoming events for your licensed series:

```bash
GET https://api.dirtiq.com/v1/events?series=lucas_oil_late_models&status=upcoming
Authorization: Bearer YOUR_API_KEY
```

```json
{
  "data": [
    {
      "event_id": "evt_2024_slinger_nationals",
      "name": "Slinger Nationals — Lucas Oil Late Models",
      "track_id": "trk_slinger",
      "series": "lucas_oil_late_models",
      "scheduled_date": "2024-08-16",
      "entry_list_published": true,
      "lines_available": true
    }
  ]
}
```

---

## Step 2: Pull opening lines

Once `lines_available: true`, retrieve the full odds object for the event:

```bash
GET https://api.dirtiq.com/v1/odds/evt_2024_slinger_nationals
Authorization: Bearer YOUR_API_KEY
```

```json
{
  "event_id": "evt_2024_slinger_nationals",
  "market": "feature_winner",
  "line_status": "open",
  "model_version": "2024-08",
  "generated_at": "2024-08-15T14:22:00Z",
  "drivers": [
    {
      "driver_id": "drv_42",
      "name": "Brandon Overton",
      "car_number": "76",
      "implied_probability": 0.21,
      "american_odds": -165,
      "decimal_odds": 1.61,
      "fractional_odds": "61/100",
      "model_edge": 0.03
    },
    {
      "driver_id": "drv_18",
      "name": "Jonathan Davenport",
      "car_number": "49",
      "implied_probability": 0.18,
      "american_odds": -125,
      "decimal_odds": 1.80,
      "fractional_odds": "4/5",
      "model_edge": -0.01
    }
  ],
  "overround": 1.12,
  "confidence": 0.84
}
```

`model_edge` is the difference between the model's implied probability and the market line after overround — positive values indicate the driver is underpriced relative to the model.

---

## Step 3: Register for line updates

Subscribe to real-time odds pushes so your trading desk sees recalculations before your book takes exposure:

```bash
POST https://api.dirtiq.com/v1/webhooks
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "url": "https://your-trading-platform.com/hooks/dirtiq",
  "events": ["odds.updated", "odds.suspended", "sharp_alert.triggered"],
  "series": ["lucas_oil_late_models"]
}
```

You'll receive a push within seconds of each qualifying session, heat race result, or significant condition change.

## Step 4: Handle a line update

Example push payload when heat race results trigger a recalculation:

```json
{
  "id": "whevt_01hx9p4n",
  "type": "odds.updated",
  "trigger": "heat_results",
  "event_id": "evt_2024_slinger_nationals",
  "market": "feature_winner",
  "timestamp": "2024-08-16T20:14:32Z",
  "changes": [
    {
      "driver_id": "drv_42",
      "prev_american_odds": -165,
      "new_american_odds": -200,
      "prev_implied_probability": 0.21,
      "new_implied_probability": 0.26,
      "trigger_reason": "won_heat_dominant"
    }
  ]
}
```

## Step 5: Monitor sharp alerts

If a sharp money signal fires, the feed pushes a `sharp_alert.triggered` event:

```json
{
  "type": "sharp_alert.triggered",
  "event_id": "evt_2024_slinger_nationals",
  "driver_id": "drv_77",
  "alert_level": "medium",
  "deviation_score": 2.4,
  "message": "Unusual volume on drv_77 at +350; model implies +520. Consider line review."
}
```

See [Sharp Money Detection](/analytics/sharp-money) for the full algorithm description.
