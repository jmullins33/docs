## Data source

All LOLMDS data in Dirt IQ originates from **DIRTRACKR** and **The Third Turn** wiki, supplemented by official series press releases at [lucasdirt.com](https://lucasdirt.com). Coverage spans the full series history from 2005 to present.

## Data buckets

Buckets are the primary filter units in the Dirt IQ API. Every driver, event, and odds object carries bucket tags that enable comparison across cohorts.

### Bucket 1 — Driver tier (career wins)

Groups drivers by all-time series wins. Used to weight field-depth calculations and calibrate overround by market competitiveness.

| Bucket key | Label | Criteria |
|---|---|---|
| `tier_elite` | Elite | 50+ career LOLMDS wins |
| `tier_contender` | Contender | 20–49 wins |
| `tier_regular` | Regular | 5–19 wins |
| `tier_occasional` | Occasional | 1–4 wins |
| `tier_rookie` | Rookie / No win | 0 wins in series |

```bash
GET /drivers?bucket=tier_elite&series=lucas_oil_late_models
```

### Bucket 2 — Championship era

Groups seasons into eras for historical analysis. Era boundaries reflect meaningful shifts in dominant drivers and field composition.

| Bucket key | Label | Years | Dominant driver(s) |
|---|---|---|---|
| `era_founding` | Founding Era | 2005–2008 | Earl Pearson Jr. |
| `era_bloomquist` | Bloomquist Era | 2009–2010 | Scott Bloomquist |
| `era_owens` | Owens Era | 2011–2013 | Jimmy Owens |
| `era_transition` | Transition | 2014–2016 | O'Neal, Davenport, Bloomquist |
| `era_davenport` | Davenport Era | 2017–2020 | Richards, Davenport, Owens |
| `era_modern` | Modern Era | 2021–present | McCreadie, O'Neal, Thornton, Moran |

```bash
GET /events?era=era_davenport&series=lucas_oil_late_models
GET /odds/compare?bucket_a=era_davenport&bucket_b=era_modern&metric=win_distribution
```

### Bucket 3 — Event tier (purse / prestige)

Groups individual races by prize money and prestige. Higher-tier events attract larger, stronger fields — which requires downward model adjustments for typical regular-season calibrations.

| Bucket key | Label | Criteria | Examples |
|---|---|---|---|
| `event_major` | Major ($50k+) | Feature purse ≥ $50,000 | Dirt Track World Championship, Eldora Dream, Knoxville Nationals |
| `event_premier` | Premier ($10k–$49k) | Feature purse $10k–$49k | Show-Me 100, Silver Dollar Nationals |
| `event_standard` | Standard | Feature purse < $10k | Regular series points events |

```bash
GET /events?event_tier=event_major&series=lucas_oil_late_models
```

### Bucket 4 — Track type

Groups tracks by configuration. Track type is a significant predictor variable — some drivers heavily favor flat, high-banked tracks while others excel on flatter 3/8-mile venues.

| Bucket key | Label | Criteria | Example tracks |
|---|---|---|---|
| `track_half_mile` | Half-mile | Track length ≥ 0.45mi | Eldora Speedway (0.5mi), Lucas Oil Speedway (0.5mi) |
| `track_third_mile` | 3/8-mile | Length 0.3mi–0.44mi | Knoxville Raceway (0.5mi clay oval), Tri-City Speedway |
| `track_short` | Short (1/4 mile) | Length < 0.3mi | Various regional venues |
| `track_high_banked` | High-banked | Banking > 20° | Eldora, Bristol (dirt events) |
| `track_flat` | Flat | Banking ≤ 12° | Various flat tracks |

```bash
GET /drivers/drv_42/history?track_bucket=track_half_mile
```

### Bucket 5 — Surface condition at race time

Groups events by the track condition score recorded at feature start. Critical for surface-split analysis.

| Bucket key | Label | Condition score range |
|---|---|---|
| `surface_heavy` | Heavy | 61–100 |
| `surface_tacky` | Tacky / Ideal | 41–60 |
| `surface_slick` | Slick | 0–40 |

```bash
GET /drivers/drv_42/results?surface_bucket=surface_slick&series=lucas_oil_late_models
```

### Bucket 6 — Season performance tier

Groups a driver's individual season by win count — useful for identifying breakout years vs. down years.

| Bucket key | Label | Wins in season |
|---|---|---|
| `season_dominant` | Dominant | 10+ wins |
| `season_strong` | Strong | 5–9 wins |
| `season_average` | Average | 2–4 wins |
| `season_lean` | Lean | 0–1 wins |

Notable dominant seasons:
- Ricky Thornton Jr. 2023: ~23 wins (`season_dominant`)
- Jonathan Davenport 2022: ~21 wins (`season_dominant`)
- Devin Moran 2025: 9 wins (`season_strong`)

```bash
GET /seasons?season_bucket=season_dominant&series=lucas_oil_late_models
```

## Comparing buckets

The `/compare` endpoint accepts two bucket definitions and a metric, and returns side-by-side statistics.

### Syntax

```bash
GET /compare?bucket_a={key}&bucket_b={key}&metric={metric}&series=lucas_oil_late_models
```

### Available metrics for comparison

| Metric key | Description |
|---|---|
| `win_distribution` | Win share % across drivers in each bucket |
| `avg_field_size` | Average number of starters per event |
| `avg_implied_prob_leader` | Average Dirt IQ implied probability for the top-ranked driver |
| `upset_rate` | % of events won by a driver outside the top-3 favorites |
| `condition_score_avg` | Average track condition score at race time |
| `dominant_driver_share` | % of wins captured by the single top driver in the bucket |

### Example: Modern era vs. Davenport era

```bash
GET /compare?bucket_a=era_davenport&bucket_b=era_modern&metric=win_distribution&series=lucas_oil_late_models
```

```json
{
  "bucket_a": {
    "key": "era_davenport",
    "label": "Davenport Era (2017–2020)",
    "events": 147,
    "unique_winners": 18,
    "dominant_driver_share": 0.31,
    "avg_implied_prob_leader": 0.26,
    "upset_rate": 0.22
  },
  "bucket_b": {
    "key": "era_modern",
    "label": "Modern Era (2021–present)",
    "events": 198,
    "unique_winners": 31,
    "dominant_driver_share": 0.21,
    "avg_implied_prob_leader": 0.21,
    "upset_rate": 0.29
  },
  "interpretation": "The Modern Era is more competitive — 31 unique winners vs. 18, lower dominant-driver concentration, and a higher upset rate. Model confidence and top-driver implied probabilities are correspondingly lower."
}
```

### Example: Elite tier on slick vs. heavy surface

```bash
GET /compare?bucket_a=tier_elite+surface_slick&bucket_b=tier_elite+surface_heavy&metric=win_distribution
```

Bucket combinations use `+` to intersect two filters (drivers in `tier_elite` who competed in `surface_slick` events, vs. the same pool in `surface_heavy` events).

### Example: Major events vs. standard events

```bash
GET /compare?bucket_a=event_major&bucket_b=event_standard&metric=upset_rate
```

Major events (`$50k+`) historically have a higher upset rate than standard points events — useful for calibrating overround decisions on marquee races.

## Applying buckets to odds requests

Pass `bucket_context` in an odds request to tell the model which peer group to use for calibration:

```json
{
  "event_id": "evt_2024_eldora_dream",
  "market": "feature_winner",
  "bucket_context": {
    "event_tier": "event_major",
    "surface_condition": "surface_tacky"
  }
}
```

The model selects the peer group matching those buckets, recalibrates field-depth expectations, and adjusts overround recommendations accordingly. Major events with large, loaded fields get higher recommended margins.
