## Triggers for line recalculation

Dirt IQ recalculates odds automatically when any of the following occur:

| Trigger | Typical odds impact |
|---|---|
| Hot laps / qualifying complete | Low–medium; adjusts for observed pace |
| Heat race result posted | Medium–high; starting position and heat performance are significant signals |
| Track condition score shifts ±10 points | Medium; affects drivers with pronounced surface splits |
| Weather alert (precipitation forecast changes) | Low–medium; primarily affects cancellation risk |
| Scratch / DNS posted | High; probability redistributed across remaining drivers |

---

## Update latency

| Trigger type | Median update latency | P95 latency |
|---|---|---|
| Heat race result (DIRTRACKR post) | 45 seconds | 90 seconds |
| Live timing integration (direct feed) | < 5 seconds | 15 seconds |
| Weather condition update | 5 minutes (batch) | 10 minutes |
| Manual scratch / operator note | < 10 seconds | 30 seconds |

DIRTRACKR-sourced results require an ingestion round-trip, which introduces the bulk of the latency. Tracks with direct timing integrations get significantly faster updates.

## The update payload

When lines change, the `odds.updated` webhook fires with a `changes` array showing only what moved:

```json
{
  "type": "odds.updated",
  "trigger": "heat_results",
  "event_id": "evt_2024_slinger_nationals",
  "timestamp": "2024-08-16T20:14:32Z",
  "changes": [
    {
      "driver_id": "drv_42",
      "prev_american_odds": -165,
      "new_american_odds": -200,
      "prev_implied_probability": 0.21,
      "new_implied_probability": 0.26,
      "trigger_reason": "won_heat_dominant",
      "positions_moved": null
    },
    {
      "driver_id": "drv_18",
      "prev_american_odds": -125,
      "new_american_odds": +110,
      "prev_implied_probability": 0.18,
      "new_implied_probability": 0.12,
      "trigger_reason": "lost_heat_back_of_pack",
      "positions_moved": null
    }
  ]
}
```

`trigger_reason` is a human-readable string explaining the primary driver of the change — useful for audit logs and trading desk context.

## Scratch handling

When a driver scratches or is marked DNS, their probability mass is redistributed proportionally across the remaining field:

```json
{
  "type": "odds.updated",
  "trigger": "scratch",
  "scratched_driver": {
    "driver_id": "drv_77",
    "name": "Chris Madden",
    "prev_implied_probability": 0.15,
    "scratch_reason": "mechanical_dns"
  },
  "field_adjustment": "probability redistributed to remaining 33 drivers"
}
```

All drivers in the field receive proportionally adjusted lines in the same payload.

---

## Polling vs. webhooks

| Approach | Recommended for |
|---|---|
| Webhook (`odds.updated`) | Primary integration for any real-time trading platform |
| Poll `GET /odds/{event_id}` | Backup, reconciliation, or low-frequency operators |

Polling is rate-limited to once per 60 seconds per event on Starter plans. Pro and Enterprise have no polling restrictions. However, webhooks are always lower-latency and preferred for race-night operations.

---

## Odds suspension

When the feature event start is detected (via timing feed or manual trigger), Dirt IQ fires `odds.suspended` and stops recalculating:

```json
{
  "type": "odds.suspended",
  "event_id": "evt_2024_slinger_nationals",
  "reason": "feature_start",
  "timestamp": "2024-08-16T21:02:00Z"
}
```

Odds remain suspended until results are posted and the market settles. Operators should use this event to close betting on their platform.
