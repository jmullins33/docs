## Why weather matters in dirt track racing

Weather is arguably the single biggest external variable in dirt track racing. Rain before a race creates a heavy, multi-groove surface that rewards powerful, aggressive setups. A hot, dry, windy afternoon can turn that same track into a one-lane parade by the time the feature runs.

Dirt IQ fuses hyperlocal weather data directly into the track condition and prediction models so that weather impacts are automatically reflected in every output.

---

## Data sources

Dirt IQ pulls from three weather data tiers, in priority order:

<Steps>
  <Step title="On-site weather station">
    If the track has registered a weather station with Dirt IQ, that station's readings are used directly. Readings are ingested every 5 minutes. This is the most accurate option and produces the highest `confidence` scores.
  </Step>
  <Step title="Nearby ASOS / AWOS station">
    For tracks without a registered station, Dirt IQ uses the closest FAA ASOS/AWOS airport weather station within 30 miles. Accuracy decreases with distance and elevation difference.
  </Step>
  <Step title="Grid-based NWS forecast">
    For events more than 24 hours in the future, Dirt IQ uses National Weather Service gridded forecasts at 2.5km resolution. These are updated hourly and provide temperature, precipitation probability, humidity, and wind.
  </Step>
</Steps>

## Weather variables used

| Variable | How it's used |
|---|---|
| Precipitation (last 24h, last 48h) | Primary driver of moisture index |
| Precipitation forecast (next 4h) | Adjusts condition evolution curve; rain mid-program has large impact |
| Air temperature | Combined with dew point to calculate evaporation rate |
| Dew point | High dew point slows surface drying significantly |
| Wind speed and direction | Higher wind speed accelerates evaporative drying |
| Track surface temperature | Derived from solar radiation and air temp; direct input to moisture model |
| Cloud cover | Modulates solar radiation and surface heating |

## Weather-adjusted predictions

Weather feeds into predictions in two ways:

### 1. Track condition adjustment

Weather data updates the live track condition score before every prediction recalculation. A sudden rain shower mid-program will spike the moisture index and shift the condition score upward, increasing the win probabilities of drivers with strong heavy-track profiles.

### 2. Driver-specific weather sensitivity

Some drivers have measurably different performance depending on weather-driven surface changes. Dirt IQ tracks this at the individual level:

```json
"weather_sensitivity": {
  "heavy_to_slick_transition": "positive",
  "rain_cancellation_risk": 0.12
}
```

- `heavy_to_slick_transition: "positive"` — this driver tends to get better relative to the field as the track dries
- `rain_cancellation_risk` — probability that the event is rained out based on current forecast

## Rain-out probability

Every prediction includes a `cancellation_risk` field for events within 12 hours:

```json
{
  "event_id": "evt_2024_jackson_motorplex",
  "cancellation_risk": 0.18,
  "forecast_summary": "Scattered showers possible after 8pm; 0.2in accumulation chance"
}
```

This is derived from NWS hourly precipitation probability and historical rain-out rates for that track's geography and month.

## Registering a weather station

To connect your track's on-site weather station:

1. Go to **Dashboard → Tracks → Your Track → Weather Station**
2. Enter the station's IP address or API endpoint
3. Confirm the Dirt IQ data schema is being sent (see below)

### Required data format

Your station must POST data every 5 minutes to:

```
POST https://api.dirtiq.com/v1/tracks/{track_id}/weather
```

With the following JSON body:

```json
{
  "timestamp": "2024-08-10T19:35:00Z",
  "temp_f": 84.2,
  "humidity_pct": 52.0,
  "wind_mph": 8.3,
  "wind_direction_deg": 225,
  "precip_last_hour_in": 0.0,
  "surface_temp_f": 101.4
}
```

## Using a custom weather station ID

If a specific race event is at a location better served by a different station than the track's default, pass `weather_station_id` in your prediction request:

```json
{
  "event_id": "evt_2024_special_event",
  "division": "sprint_wing",
  "weather_station_id": "KWST_custom_01"
}
```
