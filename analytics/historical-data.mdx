## Data source: DIRTRACKR

Dirt IQ's historical results database is built on top of **DIRTRACKR**, which maintains structured race results for Lucas Oil Late Models and affiliated dirt series going back to 2010. DIRTRACKR data is ingested nightly and normalized into the Dirt IQ schema.

Coverage:

| Series | Since | Events | Completeness |
|---|---|---|---|
| Lucas Oil Late Models | 2010 | ~300+ | Full finishing order, DNFs, DNQs |
| World of Outlaws STS | 2012 | ~500+ | Full finishing order |
| CARS Tour | 2015 | ~150+ | Full finishing order |
| Regional / outlaw late models | Varies | Partial | Best-effort via DIRTRACKR community submissions |

## Using historical data for model validation

Licensed operators and integration partners can pull historical results to backtest their own models or validate Dirt IQ's accuracy:

```bash
GET /events?series=lucas_oil_late_models&status=completed&since=2021-01-01
```

Each completed event includes:

```json
{
  "event_id": "evt_2023_eldora_dream",
  "series": "lucas_oil_late_models",
  "track_id": "trk_eldora",
  "date": "2023-06-09",
  "status": "completed",
  "finishing_order": [
    {
      "position": 1,
      "driver_id": "drv_18",
      "name": "Jonathan Davenport",
      "car_number": "49",
      "laps_led": 28,
      "fastest_lap_ms": 14021,

  "caution_count": 3,

  "track_condition_score_at_finish": 38.4,

```

## Historical odds archive

For events where Dirt IQ generated lines, the odds archive is available:

```bash
GET /odds?event_id=evt_2023_eldora_dream&include_history=true
```

Response includes opening lines, each recalculation checkpoint, and the final pre-feature lines — useful for measuring closing line value and calibrating your own margin decisions.

## Driver career records

Pull a driver's full results history in the Dirt IQ database:

```bash
GET /drivers/drv_18/results?series=lucas_oil_late_models
GET /drivers/drv_18/results?track_id=trk_eldora
GET /drivers/drv_18/results?since=2022-01-01&condition_band=slick
```

Filtering by `condition_band` (heavy, tacky, slick) is particularly useful for building your own surface-split analysis.

## Bulk data export

For large-scale backtesting or external modeling, request a bulk export:

```bash
POST /exports
{
  "dataset": "results",
  "series": "lucas_oil_late_models",
  "since": "2015-01-01",
  "format": "csv"
}
```

Available datasets:

| Dataset | Description |
|---|---|
| `results` | Full finishing orders for all events |
| `odds_history` | Opening and checkpoint odds for all modeled events |
| `driver_profiles` | Metric snapshots at time of each event |
| `conditions` | Track condition scores per event |

Exports are delivered as `.csv.gz` to your registered email within 15 minutes for requests under 500k rows, longer for larger pulls.

## DIRTRACKR data gaps

DIRTRACKR coverage is comprehensive for national Lucas Oil events but has known gaps:

- **Regional outlaw events**: coverage varies by region; community-submitted results may be incomplete
- **Qualifying / time trial data**: not consistently available before 2018
- **Lap-by-lap data**: not available in DIRTRACKR; requires direct timing system integration

When Dirt IQ encounters a data gap for a driver (fewer than 3 series starts), their prior is regressed toward the population mean rather than excluded from the model.
