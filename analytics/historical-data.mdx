## What historical data is available

Dirt IQ maintains a structured archive of:

| Dataset | Depth | Update Frequency |
|---|---|---|
| Race results (finishes, DNFs, DNQs) | 2010 to present | After each event |
| Track condition logs | 2018 to present | After each event |
| Lap timing data | 2020 to present (varies by track) | After each event |
| Weather station readings | 2021 to present | 5-minute intervals |
| Prediction archives | 2022 to present | Per prediction generated |

## Accessing historical results

### By event

```bash
GET /events/{event_id}/results
```

Returns the full finishing order, DNFs, and key timing stats for a completed event.

```json
{
  "event_id": "evt_2023_knoxville_nationals_feature",
  "track_id": "trk_knoxville",
  "division": "sprint_wing",
  "date": "2023-08-12",
  "finishing_order": [
    {
      "position": 1,
      "driver_id": "drv_17",
      "name": "David Gravel",
      "car_number": "2",
      "laps_led": 24,
      "fastest_lap_ms": 13842
    },
    {
      "position": 2,
      "driver_id": "drv_9",
      "name": "Donny Schatz",
      "car_number": "15",
      "laps_led": 1,
      "fastest_lap_ms": 13891
    }
  ],
  "total_laps": 30,
  "caution_count": 2,
  "track_condition_score_at_start": 58.1,
  "track_condition_score_at_finish": 34.7

```

### By driver

```bash
GET /drivers/{driver_id}/results?division=sprint_wing&since=2023-01-01
```

Returns all results for a driver within the specified filters. Supports pagination.

### By track

```bash
GET /tracks/{track_id}/results?year=2023
```

Returns all events held at a specific track for the given year.

## Track condition history

Retrieve how conditions evolved over the course of a race night:

```bash
GET /tracks/{track_id}/conditions?date=2024-08-10
```

```json
{
  "track_id": "trk_eldora",
  "date": "2024-08-10",
  "readings": [
    { "time": "17:00", "condition_score": 78.2, "source": "weather_station" },
```

## Prediction archives

Compare past predictions against actual results to evaluate model accuracy or build your own calibration layer:

```bash
GET /predictions?event_id=evt_2023_knoxville_nationals&status=completed
```

Each archived prediction includes the original driver rankings and probabilities, plus the actual result — useful for backtesting strategies on top of Dirt IQ data.

## Bulk data export

For large-scale analysis, use the bulk export endpoint:

```bash
POST /exports
Content-Type: application/json

{
  "dataset": "results",
  "division": "sprint_wing",
  "track_id": "trk_knoxville",
  "since": "2015-01-01",
  "until": "2024-01-01",
  "format": "csv"
}
```

Exports are processed asynchronously. A download URL is sent to your registered email and is available for 72 hours. Large exports (>100k rows) are delivered as compressed `.csv.gz` files.

### Available datasets for export

| Dataset key | Description |
|---|---|
| `results` | Race finishing orders with lap times |
| `conditions` | Track condition scores per event |
| `predictions` | Full prediction archives with actuals |
| `driver_profiles` | Snapshot of driver metrics at event time |
| `weather` | Weather station readings by track and date |
