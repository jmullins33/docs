## When lines become available

Lines are generated as soon as the entry list for an event is published and marked complete in DIRTRACKR. The API field `lines_available` on the event object transitions from `false` to `true`, and a `odds.published` webhook fires to all licensed subscribers.

Typical timeline for a Lucas Oil national event:

| Milestone | Lines status |
|---|---|
| Entry list published (T-2 days) | Opening lines generated; `odds.published` webhook fires |
| Hot laps / time trials (day-of) | Lines recalculated with qualifying data |
| Heat race 1 complete | Lines recalculated |
| Heat race 2–4 complete | Lines recalculated |
| Feature starts | Lines suspended; `odds.suspended` fires |
| Feature complete | Results posted; market settled |

## What the odds object contains

```json
{
  "event_id": "evt_2024_slinger_nationals",
  "market": "feature_winner",
  "line_status": "open",
  "model_version": "2024-08",
  "generated_at": "2024-08-15T14:22:00Z",
  "track_condition_score": 64.1,
  "confidence": 0.84,
  "overround": 1.11,
  "drivers": [
    {
      "driver_id": "drv_42",
      "name": "Brandon Overton",
      "car_number": "76",
      "implied_probability": 0.21,
      "american_odds": -165,
      "decimal_odds": 1.61,
      "fractional_odds": "61/100",
      "model_edge": 0.03,
      "form_score": 88.1,
      "track_affinity": 91.4
    }
  ]
}
```

Key fields:

| Field | Description |
|---|---|
| `implied_probability` | Model probability after overround margin applied |
| `american_odds` | Standard American moneyline format |
| `decimal_odds` | European decimal format |
| `model_edge` | Difference between model probability and market line — positive = underpriced by model |
| `overround` | Total market book (1.10 = 10% margin) |
| `confidence` | Model confidence (0–1); lower when entry list is thin or conditions data is missing |

## Available markets

| Market | Description | Availability |
|---|---|---|
| `feature_winner` | Outright winner of the feature event | All events |
| `top_3_finish` | Driver finishes in top 3 | All events |
| `top_5_finish` | Driver finishes in top 5 | All events |
| `head_to_head` | Which of two drivers finishes higher | On request |
| `winning_margin` | Whether winner leads by 1s, 2s, or 3s+ | Beta |

Additional markets can be structured on request for licensed operators.

---

## Odds formats

All formats are returned in every response. Set your preferred format via the `Accept-Odds-Format` header:

```
Accept-Odds-Format: american   # default
Accept-Odds-Format: decimal
Accept-Odds-Format: fractional
```

---

## Suspending and settling

Dirt IQ automatically fires `odds.suspended` at feature start. Operators are responsible for their own in-play decisions — Dirt IQ does not currently support in-race live betting lines.

After results post to DIRTRACKR (typically within 30 minutes of the feature), the event transitions to `settled` and the `event.settled` webhook fires with the final finishing order for reconciliation.
