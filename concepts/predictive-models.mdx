## Overview

Dirt IQ uses a two-stage modeling architecture:

1. **Bayesian odds engine** — generates probability estimates per driver based on priors built from historical results
2. **ML regression layer** — adjusts those probabilities using event-specific covariates (track conditions, weather, qualifying pace)

Outputs are then converted to market odds with an operator-configurable overround margin.

---

## Stage 1: Bayesian odds engine

### Prior construction

For each driver, we build a prior probability distribution over finishing positions using their full DIRTRACKR results history. The prior is:

- Weighted by recency (exponential decay; half-life = 90 days)
- Conditioned on series (Lucas Oil Late Models vs. regional results receive separate weights)
- Conditioned on track type (half-mile, short, flat, banked)
- Calibrated for field depth — a win in a 35-car national field counts more than a win in a 12-car regional

```
P(win | driver, event) ∝ prior_win_rate × field_depth_factor × recency_weight
```

### Likelihood update

When new information arrives — entry list finalized, qualifying complete, heat races run — the engine performs a Bayesian update:

```
P(win | driver, event, new_data) ∝ P(new_data | driver, event) × P(win | driver, event)
```

This means opening lines (entry list only) are conservative and widen as information accumulates. By the time heat races are complete, the model has substantially more signal and line confidence is higher.

### Field normalization

Raw win probabilities across the entry list are normalized so they sum to 1.0. The engine then applies the overround margin (configurable per operator, default 10–15%) to produce the published implied probabilities and odds.

---

## Stage 2: ML regression adjustments

A gradient-boosted regression model adjusts the Bayesian base probabilities using features the prior doesn't capture:

| Feature | Description |
|---|---|
| Track condition score | Surface moisture and groove state at time of lines generation |
| Temperature delta | Air vs. surface temp; affects tire compound performance |
| Wind speed | High wind disfavors certain car setups |
| Days since last race | Rest/fatigue signal |
| Starting position (if known) | Post-qualifying or heat draw |
| Heat race lap time delta | Driver's pace vs. field median in heat |
| Crew chief change flag | Flagged manually; material signal in late models |

The regression model is retrained quarterly on the previous season's data.

## Opening line generation pipeline

```
DIRTRACKR results ingested
         ↓
Driver priors updated (nightly batch)
         ↓
Entry list published for event
         ↓
Bayesian engine scores each driver
         ↓
ML regression applies condition adjustments
         ↓
Probabilities normalized + overround applied
         ↓
Opening odds published to API (lines_available: true)
         ↓
Webhook push to licensed operators
```

## Model accuracy

Backtested against 2021–2023 Lucas Oil Late Model seasons:

| Metric | Score |
|---|---|
| Top-pick win rate (opening lines) | 20.8% (vs. 12.1% random baseline for avg field of ~35) |
| Implied probability calibration | Brier score 0.131 |
| Top-3 hit rate when implied prob > 0.40 | 58.4% |
| Overround efficiency (closing line value) | +4.1% vs. sharp closing lines |

Calibration plots and full backtesting reports are available to licensed operators on request.

## Overround and margin configuration

Operators can configure the overround margin on their account:

```json
{
  "operator_id": "op_abc123",
  "default_overround": 0.12,
  "per_series_overround": {
    "lucas_oil_late_models": 0.10,
    "world_of_outlaws_sts": 0.13
  }
}
```

Higher margins protect the book but reduce competitiveness. Dirt IQ recommends 10–12% for feature winner markets in dirt late models given the relatively low liquidity.
