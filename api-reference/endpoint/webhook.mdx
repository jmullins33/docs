## Overview

Register a webhook endpoint to receive `POST` requests from Dirt IQ whenever predictions are updated or track conditions change. This is the recommended approach for live dashboards, fantasy platforms, and broadcast overlays.

---

## Registering a webhook

```bash
POST https://api.dirtiq.com/v1/webhooks
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "url": "https://yourapp.com/webhooks/dirtiq",
  "events": ["prediction.updated", "track_conditions.changed", "race.caution", "race.complete"]
}
```

You can register up to 10 webhook endpoints per account. Each endpoint can subscribe to any subset of event types.

---

## Event types

| Event | When it fires |
|---|---|
| `prediction.updated` | Win probabilities recalculated (qualifying, heat results, lap data, weather change) |
| `track_conditions.changed` | Condition score shifts by ±10 points or more |
| `race.caution` | Caution period detected from timing feed |
| `race.complete` | Feature event finishes; final results posted |

## Verifying webhook signatures

Every request from Dirt IQ includes a `Dirt-IQ-Signature` header. Verify it to confirm the request is genuine:

```python
import hmac
import hashlib

def verify_signature(payload_body: bytes, secret: str, signature_header: str) -> bool:
    expected = hmac.new(
        secret.encode(),
        payload_body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature_header)
```

Your webhook secret is available from **Dashboard → Webhooks → [Endpoint] → Secret**. Rotate it at any time — the old secret remains valid for 5 minutes after rotation to avoid dropped events during deployment.

---

## Retries

If your endpoint returns anything other than `2xx`, Dirt IQ retries the delivery with exponential backoff:

| Attempt | Delay |
|---|---|
| 1st retry | 30 seconds |
| 2nd retry | 5 minutes |
| 3rd retry | 30 minutes |
| 4th retry | 2 hours |

After 4 failed retries, the event is marked as undelivered. You can replay undelivered events from the dashboard for up to 72 hours.

## Testing locally

Use the Dirt IQ CLI to send test webhook events to a local server:

```bash
dirtiq webhooks trigger prediction.updated \
  --event-id evt_2024_knoxville_nationals \
  --url http://localhost:3000/webhooks/dirtiq
```

Or use a tunneling tool like ngrok to expose your local server and register it as a real endpoint.
