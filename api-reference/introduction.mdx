## Base URL

```
https://api.dirtiq.com/v1
```

---

## Authentication

All requests require a Bearer token in the `Authorization` header:

```bash
Authorization: Bearer YOUR_API_KEY
```

API keys are scoped to your operator account and licensed series. A key for `lucas_oil_late_models` will not return data for unlicensed series. Keys are managed from the [operator portal](https://app.dirtiq.com/api-keys).

<Warning>
  Never expose your API key in client-side code or commit it to source control. Rotate compromised keys immediately from the operator portal.
</Warning>

---

## Request and response format

All `POST` and `PATCH` requests must include:

```
Content-Type: application/json
```

Responses are always JSON. Errors use a consistent structure:

```json
{
  "error": 422,
  "message": "series 'nascar_cup' is not licensed on your account"
}
```

## Core endpoints

| Endpoint | Description |
|---|---|
| `GET /events` | List upcoming and completed events for your licensed series |
| `GET /odds/{event_id}` | Retrieve current odds for an event |
| `POST /odds` | Request odds for a specific event and market (on-demand) |
| `DELETE /odds/{id}` | Remove a stored odds snapshot |
| `POST /webhooks` | Register a webhook endpoint |
| `POST /risk/bets` | Push bet-level data for pattern detection |
| `GET /drivers/{id}` | Retrieve driver profile and metrics |

Full schema reference for each endpoint is in the sections below.

## Rate limits

| Plan | Requests / minute | Burst |
|---|---|---|
| Starter | 60 | 120 |
| Pro | 300 | 600 |
| Enterprise | Unlimited | — |

Headers on every response:

```
X-RateLimit-Limit: 300
X-RateLimit-Remaining: 284
X-RateLimit-Reset: 1723305060
```

`429 Too Many Requests` is returned when the limit is exceeded. Use exponential backoff before retrying.

---

## Pagination

List endpoints use cursor-based pagination:

```bash
GET /events?limit=20&after=evt_01hx9p4n
```

```json
{
  "data": [...],
  "pagination": {
    "has_more": true,
    "next_cursor": "evt_01hx7k2m"
  }
}
```

## Versioning

Current stable version: **v1**. Breaking changes will ship under `/v2`. Non-breaking additions (new fields, optional parameters) are deployed to v1 without notice.

To pin to a specific monthly release:

```
Dirt-IQ-Version: 2024-08
```

---

## Odds format

Default is American moneyline. Override per-request:

```
Accept-Odds-Format: american    # default
Accept-Odds-Format: decimal
Accept-Odds-Format: fractional
```
