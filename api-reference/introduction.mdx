## Base URL

All API requests are made to:

```
https://api.dirtiq.com/v1
```

---

## Authentication

Every request must include an `Authorization` header with a Bearer token:

```bash
Authorization: Bearer YOUR_API_KEY
```

API keys are scoped to your account and can be created or revoked from the [Dirt IQ dashboard](https://app.dirtiq.com/api-keys). Use separate keys for development and production environments.

<Warning>
  Never expose your API key in client-side code or commit it to source control. If a key is compromised, revoke it immediately from the dashboard.
</Warning>

---

## Request format

All `POST` and `PATCH` requests must send JSON with the appropriate content type header:

```
Content-Type: application/json
```

---

## Response format

Responses are always JSON. Successful responses return HTTP `200` or `201`. Error responses return a consistent error object:

```json
{
  "error": 422,
  "message": "division must be one of: sprint_wing, sprint_nonwing, late_model, modified, street_stock, micro_sprint"
}
```

---

## Rate limits

| Plan | Requests / minute | Burst |
|---|---|---|
| Starter | 60 | 120 |
| Pro | 300 | 600 |
| Enterprise | Custom | Custom |

Rate limit headers are included in every response:

```
X-RateLimit-Limit: 300
X-RateLimit-Remaining: 284
X-RateLimit-Reset: 1723305000
```

When the limit is exceeded, the API returns `429 Too Many Requests`. Implement exponential backoff before retrying.

---

## Versioning

The current stable API version is **v1**. Breaking changes will be introduced under a new version prefix (e.g., `/v2`). Non-breaking additions (new fields, new optional parameters) are made to the existing version without notice.

To pin to a specific minor version, pass a version header:

```
Dirt-IQ-Version: 2024-08
```

---

## Pagination

List endpoints support cursor-based pagination:

```bash
GET /predictions?limit=20&after=pred_01hx7k2m
```

Responses include a `pagination` object:

```json
{
  "data": [...],
  "pagination": {
    "has_more": true,
    "next_cursor": "pred_01hx9p4n"
  }
}
```

Pass `next_cursor` as the `after` parameter in your next request.
