## Data buckets

### Bucket 1 — Driver tier (career wins)

| Key | Label | Criteria |
|---|---|---|
| `tier_elite` | Elite | 50+ career wins |
| `tier_contender` | Contender | 20–49 wins |
| `tier_regular` | Regular | 5–19 wins |
| `tier_occasional` | Occasional | 1–4 wins |
| `tier_rookie` | Rookie / No win | 0 wins |

### Bucket 2 — Championship era

| Key | Label | Years | Dominant driver(s) |
|---|---|---|---|
| `era_founding` | Founding Era | 2005–2008 | Earl Pearson Jr. |
| `era_bloomquist` | Bloomquist Era | 2009–2010 | Scott Bloomquist |
| `era_owens` | Owens Era | 2011–2013 | Jimmy Owens |
| `era_transition` | Transition | 2014–2016 | O'Neal, Davenport, Bloomquist |
| `era_davenport` | Davenport Era | 2017–2020 | Richards, Davenport, Owens |
| `era_modern` | Modern Era | 2021–present | McCreadie, O'Neal, Thornton, Moran |

### Bucket 3 — Event tier (purse / prestige)

| Key | Label | Criteria |
|---|---|---|
| `event_major` | Major ($50k+) | Feature purse ≥ $50,000 |
| `event_premier` | Premier ($10k–$49k) | Feature purse $10k–$49k |
| `event_standard` | Standard | Feature purse < $10k |

### Bucket 4 — Track type

| Key | Label | Criteria |
|---|---|---|
| `track_half_mile` | Half-mile | Length ≥ 0.45mi |
| `track_third_mile` | 3/8-mile | Length 0.3–0.44mi |
| `track_short` | Short | Length < 0.3mi |
| `track_high_banked` | High-banked | Banking > 20° |
| `track_flat` | Flat | Banking ≤ 12° |

### Bucket 5 — Surface condition

| Key | Label | Score range |
|---|---|---|
| `surface_heavy` | Heavy | 61–100 |
| `surface_tacky` | Tacky | 41–60 |
| `surface_slick` | Slick | 0–40 |

### Bucket 6 — Season performance tier

| Key | Label | Wins in season |
|---|---|---|
| `season_dominant` | Dominant | 10+ |
| `season_strong` | Strong | 5–9 |
| `season_average` | Average | 2–4 |
| `season_lean` | Lean | 0–1 |

## Comparing buckets

```bash
GET /compare?bucket_a=era_davenport&bucket_b=era_modern&metric=win_distribution
```

```json
{
  "bucket_a": {
    "key": "era_davenport",
    "events": 147,
    "unique_winners": 18,
    "dominant_driver_share": 0.31,
    "upset_rate": 0.22
  },
  "bucket_b": {
    "key": "era_modern",
    "events": 198,
    "unique_winners": 31,
    "dominant_driver_share": 0.21,
    "upset_rate": 0.29
  }
}
```

Available comparison metrics: `win_distribution`, `avg_field_size`, `avg_implied_prob_leader`, `upset_rate`, `condition_score_avg`, `dominant_driver_share`.

Combine buckets with `+`: `tier_elite+surface_slick` filters Elite drivers in slick-surface events.
