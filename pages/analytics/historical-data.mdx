# Historical Data

## Coverage

| Dataset | Depth | Update frequency |
|---|---|---|
| Race results (finishes, DNFs, DNQs) | 2010 to present | After each event |
| Track condition logs | 2018 to present | After each event |
| Lap timing data | 2020 to present (varies by track) | After each event |
| Weather station readings | 2021 to present | 5-minute intervals |
| Odds archives | 2022 to present | Per odds object generated |

## Results by driver

```bash
GET /drivers/{driver_id}/results?series=lucas_oil_late_models&since=2022-01-01
GET /drivers/{driver_id}/results?track_id=trk_eldora
GET /drivers/{driver_id}/results?condition_band=slick
```

## Odds archive

Compare past predictions against actual results:

```bash
GET /odds?event_id=evt_2023_eldora_dream&include_history=true
```

Returns opening lines, each recalculation checkpoint, and final pre-feature lines — useful for measuring closing line value and calibrating margin decisions.

## Bulk export

```bash
POST /exports
{
  "dataset": "results",
  "series": "lucas_oil_late_models",
  "since": "2015-01-01",
  "format": "csv"
}
```

| Dataset | Description |
|---|---|
| `results` | Full finishing orders for all events |
| `odds_history` | Opening and checkpoint odds for all modeled events |
| `driver_profiles` | Metric snapshots at time of each event |
| `conditions` | Track condition scores per event |

Exports are delivered as `.csv.gz` to your registered email.
