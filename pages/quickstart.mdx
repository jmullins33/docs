# Quickstart

## Prerequisites

- A Dirt IQ operator account and API key — contact [sales@dirtiq.com](mailto:sales@dirtiq.com)
- A licensed series in your contract (e.g. `lucas_oil_late_models`)

---

## Step 1: Get your API key

Log in to the [Dirt IQ dashboard](https://app.dirtiq.com), navigate to **Settings → API Keys**, and create a new key.

<Warning>
  Keep your API key secret. Never commit it to source control or expose it in client-side code.
</Warning>

---

## Step 2: Fetch the event list

```bash
GET https://api.dirtiq.com/v1/events?series=lucas_oil_late_models&status=upcoming
Authorization: Bearer YOUR_API_KEY
```

## Step 3: Pull opening lines

Once `lines_available: true`, retrieve the odds object:

<Tabs items={['cURL', 'Python', 'Node.js']}>
  <Tab>
  ```bash
  curl https://api.dirtiq.com/v1/odds/evt_2026_eldora_dream \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```
  </Tab>
  <Tab>
  ```python
  import requests

  r = requests.get(
      "https://api.dirtiq.com/v1/odds/evt_2026_eldora_dream",
      headers={"Authorization": "Bearer YOUR_API_KEY"}

  odds = r.json()
  print(odds["drivers"][0])
  ```

## Step 4: Subscribe to live updates

```bash
POST https://api.dirtiq.com/v1/webhooks
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "url": "https://your-platform.com/hooks/dirtiq",
  "events": ["odds.updated", "odds.suspended", "sharp_alert.triggered"],
  "series": ["lucas_oil_late_models"]
}
```

You'll receive a push within seconds of each qualifying session, heat race result, or significant condition change.

## Step 5: Handle line updates

```json
      "prev_american_odds": -165,
      "new_american_odds": -200,

```
