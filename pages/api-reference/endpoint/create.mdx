# Request Odds

```
POST /odds
```

Generates odds for the specified event and market. Returns the full odds object immediately (typically < 300ms).

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `event_id` | string | Yes | The event to generate odds for |
| `market` | string | No | Default: `feature_winner` |
| `overround` | float | No | Override account default (e.g. `0.12` for 12%) |
| `track_condition_override` | float | No | Manual condition score 0–100; replaces computed score |
| `include_heat_race_data` | boolean | No | Default `true` |

## Example request

```bash
curl -X POST https://api.dirtiq.com/v1/odds \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "event_id": "evt_2026_eldora_dream",
    "market": "feature_winner",
    "track_condition_override": 71.0
  }'
```
