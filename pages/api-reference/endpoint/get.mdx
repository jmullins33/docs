# List Odds

```
GET /odds
```

Returns a paginated list of odds objects. Filter by event, series, market, or status.

## Query parameters

| Parameter | Type | Description |
|---|---|---|
| `event_id` | string | Filter by event ID |
| `series` | string | e.g. `lucas_oil_late_models` |
| `market` | string | `feature_winner`, `top_3_finish`, `top_5_finish`, `head_to_head` |
| `line_status` | string | `open`, `suspended`, or `settled` |
| `limit` | integer | Results per page (default 20, max 100) |
| `after` | string | Pagination cursor from previous response |

## Example request

```bash
curl https://api.dirtiq.com/v1/odds \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -G \
  -d "series=lucas_oil_late_models" \
  -d "line_status=open" \
  -d "limit=5"
```

## Response fields

| Field | Description |
|---|---|
| `id` | Unique odds object ID |
| `line_status` | `open`, `suspended`, or `settled` |
| `track_condition_score` | 0 (slick) → 100 (heavy moisture) at time of calculation |
| `confidence` | Model confidence 0–1 |
| `overround` | Total market book (e.g. 1.11 = 11%) |
| `implied_probability` | Model probability after overround applied |
| `model_edge` | Model probability minus market line; positive = underpriced |
