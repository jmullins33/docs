# Predictive Models

Dirt IQ uses a two-stage modeling architecture:

1. **Bayesian odds engine** — generates probability estimates per driver based on priors built from historical DIRTRACKR results
2. **ML regression layer** — adjusts those probabilities using event-specific covariates (track conditions, weather, qualifying pace)

Outputs are converted to market odds with an operator-configurable overround margin.

---

## Stage 1: Bayesian odds engine

### Prior construction

For each driver, a prior probability distribution over finishing positions is built using their full DIRTRACKR results history. The prior is:

- Weighted by recency (exponential decay; half-life = 90 days)
- Conditioned on series (Lucas Oil Late Models vs. regional results receive separate weights)
- Conditioned on track type (half-mile, short, flat, banked)
- Calibrated for field depth — a win in a 35-car national field counts more than a win in a 12-car regional

```
P(win | driver, event) ∝ prior_win_rate × field_depth_factor × recency_weight
```

### Likelihood update

When new information arrives — entry list finalized, qualifying complete, heat races run — the engine performs a Bayesian update:

```
P(win | driver, event, new_data) ∝ P(new_data | driver, event) × P(win | driver, event)
```

Opening lines (entry list only) are conservative. By the time heat races are complete, the model has substantially more signal and line confidence is higher.

---

## Stage 2: ML regression adjustments

A gradient-boosted regression model adjusts the Bayesian base probabilities using features the prior doesn't capture:

| Feature | Description |
|---|---|
| Track condition score | Surface moisture and groove state at time of lines generation |
| Temperature delta | Air vs. surface temp; affects tire compound performance |
| Wind speed | High wind disfavors certain car setups |
| Days since last race | Rest/fatigue signal |
| Starting position | Post-qualifying or heat draw |
| Heat race lap time delta | Driver's pace vs. field median |
| Crew chief change flag | Flagged manually; material signal in late models |

The regression model is retrained quarterly on the previous season's data.

---

## Opening line generation pipeline

```
DIRTRACKR results ingested (nightly batch)
         ↓
Driver priors updated
         ↓
Entry list published for event
         ↓
Bayesian engine scores each driver
         ↓
ML regression applies condition adjustments
         ↓
Probabilities normalized + overround applied
         ↓
Opening odds published → webhook push to operators
```

## Confidence scores

The `confidence` field (0–1) reflects how much signal the models have:

<AccordionGroup>
  <Accordion title="What raises confidence">
    Complete entry list, weather data from a local station, track prep logs submitted, heat race results available, and drivers with 10+ starts at this venue.
  </Accordion>
  <Accordion title="What lowers confidence">
    Many drivers with limited history at this track, weather data interpolated from distant stations, unusual event format (invert race, random draw), or a new track added within the last 12 months.
  </Accordion>
</AccordionGroup>

<Tip>
  When `confidence` is below 0.6, apply additional overround margin and flag for manual trading desk review.
</Tip>

| Metric | Score |
|---|---|
| Top-pick win rate (opening lines) | 20.8% vs. 12.1% random baseline |
| Implied probability calibration (Brier score) | 0.131 |
| Top-3 hit rate when implied prob > 0.40 | 58.4% |

```json
{
  "operator_id": "op_abc123",
  "default_overround": 0.12,
  "per_series_overround": {
    "lucas_oil_late_models": 0.10,
    "world_of_outlaws_sts": 0.13
  }
}
```

Dirt IQ recommends 10–12% for feature winner markets in dirt late models given the relatively low liquidity.
